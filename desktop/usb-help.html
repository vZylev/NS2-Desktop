USB typing / Escritura USB

Compatible Apple Silicon Macs can act as a USB keyboard. A compatible, already installed and approved usbgadget.kext is required. NS2 Desktop checks the loaded driver; it does not install drivers or change macOS security settings.

Los Mac Apple Silicon compatibles pueden funcionar como un teclado USB. Se necesita usbgadget.kext compatible, instalado, autorizado y cargado. NS2 Desktop comprueba el driver; no instala drivers ni cambia la seguridad de macOS.

Unsigned kernel drivers may require changing startup security and disabling SIP, which reduces system protection. Review Apple's documentation before making those changes. Driver presence does not prove hardware compatibility.

Los drivers sin firma pueden requerir modificar la seguridad de arranque y desactivar SIP, lo que reduce la protección del sistema. Consultá la documentación de Apple antes de hacerlo. Detectar el driver no garantiza compatibilidad con el hardware.

Before typing / Antes de escribir

  • Use a USB data cable. Select US English in the console's USB keyboard settings, regardless of the Mac's layout.
    Usá un cable USB de datos y elegí inglés de EE. UU. en la configuración del teclado USB de la consola, independientemente del teclado del Mac.
  • Bootstrap: open an empty editor in slot 0. When finished, inspect and save as NS2. If interrupted, clear the partial text before retrying.
    Bootstrap: abrí un editor vacío en el slot 0. Al finalizar, revisá y guardá como NS2. Si se interrumpe, borrá el texto parcial antes de reintentar.
  • Connection commands: restart the console, open SmileBASIC, choose Make a program and focus the command entry. Start a PC session, check USB, then confirm and send. Do not enter RUN or REMOVE manually before automatic sending.
    Comandos de conexión: reiniciá la consola, abrí SmileBASIC, elegí Make a program y enfocá la entrada de comandos. Iniciá una sesión en la PC, comprobá USB, confirmá y enviá. No introduzcas RUN ni REMOVE manualmente antes del envío automático.
  • Successful typing only confirms USB delivery; watch the console and connection progress for the actual result. If command sending is interrupted or the console acquisition fails, restart the console before a new attempt.
    La escritura completada solo confirma el envío USB; verificá el resultado en la consola y en el progreso de conexión. Si se interrumpe el envío de comandos o falla la adquisición, reiniciá la consola antes de otro intento.

Troubleshooting / Diagnóstico

If no keyboard enumerates, check the data cable, try another compatible USB port/controller, and refresh driver checks. Use slower typing and longer command pauses if characters or dialogs are missed. Open USB logs for the full sequence and error details.

Si no aparece el teclado, revisá el cable de datos, probá otro puerto/controlador compatible y actualizá las comprobaciones del driver. Usá escritura más lenta y pausas más largas si se pierden caracteres o diálogos. Abrí los registros USB para ver la secuencia y el error completos.
