01 / SETUP

Connect your console

Choose the address on the same network as your console.

Choose one Switch to shorten the command. The first compatible connection using zeros is accepted; consoles are not counted automatically.

Before you start

SmileBASIC 4.4.9 · System 23.0.1 · More than 20 MiB free in the SmileBASIC save. Keep the session open while using its tools.

Enter this file in SmileBASIC slot 0 and save it as NS2. This is a one-time setup.

02 / CONNECT

Continue on your console

  1. Open SmileBASIC and choose “Make a program”.
  2. Enter these commands separately, confirming the load:
    LOAD "TXT:NS2"
RUN
REMOVE NSR,&H60000000,&H3FFFFFFF

    “Out of memory” is expected. Enter REMOVE only once per application process.

  3. Start a PC session, then enter the connection command shown below:
    Your START command will appear here.

Keep SmileBASIC and this application open until the session finishes. Restart the console when you are done.
